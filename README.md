# SaaS Platform

A modern SaaS web application built with Next.js and Supabase, focused on authentication, conversion-oriented pages, and a polished product experience.

## Highlights

- Next.js application architecture
- Supabase authentication
- Sign up and login flows
- Product, features, pricing, and testimonials pages
- Responsive modern UI
- SEO-friendly page structure
- Ready for Vercel deployment

## Tech Stack

- Next.js
- React
- Supabase
- JavaScript
- CSS

## Project Status

Active development.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Environment Variables

Create a `.env.local` file and add the required Supabase configuration:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Never commit real credentials or secrets to the repository.

## Deployment

The project is designed to be deployed on Vercel.
